**ALICED INTELIGENTE CIBERNÉTICA IA** es una plataforma web interactiva con estética cibernética/futurista que integra analítica de datos en tiempo real y procesamiento de lenguaje natural (PLN). Su núcleo conversacional, **AURA IA**, permite una interacción multimodal por texto y voz (reconocimiento de voz y síntesis hablada).

---

## 🚀 Características Principales

* **💬 Asistente IA Multimodal (AURA IA):** Integración directa con el SDK `@google/genai` utilizando el modelo `gemini-1.5-flash` para respuestas contextuales fluidas.
* **🎙️ Interacción por Voz (STT / TTS):** Implementación de la **Web Speech API** para dictado por micrófono (Speech Recognition) y lecturas con síntesis de voz (Text-to-Speech).
* **📊 Dashboard Analítico:** Gráficos dinámicos e interactivos en tiempo real impulsados por **Chart.js** para monitorear el rendimiento de la terminal.
* **🎨 Interfaz Neón/Cibernética:** Maquetación moderna, responsiva e inmersiva adaptada para entornos futuristas.
* **🔒 Seguridad de Credenciales:** Gestión aislada de claves privadas mediante variables de entorno en producción.

## 📦 Instalación y Configuración Local

Si deseas clonar y ejecutar este proyecto en tu entorno local:

### 1. Clonar el repositorio
``bash
git clone [https://github.com/menaantunm-dev/-aliced-cibernetica.git](https://github.com/menaantunm-dev/-aliced-cibernetica.git)
cd -aliced-cibernetica

Despliegue en Producción
El proyecto está optimizado para desplegarse de manera continua en Vercel:
1. Vincula el repositorio de GitHub con tu cuenta de Vercel.
2. En la sección Environment Variables, agrega ⁠VITE_GEMINI_API_KEY⁠ con tu clave de API.
3. Haz clic en Deploy.
